# Maître Mohamed - Couture et Retouche Website

## Overview
A portfolio website for Maître Mohamed, a tailor and couture specialist based in Tangier, Morocco. The site showcases his work including traditional garments, coats, sportswear, and alterations. Each product has a WhatsApp order button.

## Project Architecture
- **static/index.html** - Main HTML page (RTL Arabic layout)
- **static/styles.css** - All styling (ultra-luxury royal gold theme)
- **static/script.js** - Gallery filtering, lightbox, mobile menu, hero particles
- **static/images/** - All product/work images (63 images + logo)
- **static/images/hero-bg.png** - Hero section luxury silk fabric background
- **server.py** - Python HTTP server on port 5000

## Key Features
- RTL Arabic layout with Tajawal font
- Ultra-luxury royal black and gold color scheme
- Animated hero section with golden particles, moving gradients, silk fabric background
- Gallery with ultra-luxury golden carved frames and magical glow effects
- Category filtering (coats 18, sportswear 22, traditional 23)
- Green WhatsApp order button under each product image
- Image lightbox viewer (click image to view full size)
- WhatsApp floating contact button (fixed position)
- Responsive mobile design
- Services section
- Contact section

## Gallery Design
- Golden ornate frames (3px gold border with multi-layer box-shadow glow)
- Corner diamond ornaments via CSS pseudo-elements
- Golden shimmer animation sweeping across cards
- Radial golden glow background patterns
- Decorative section title with golden flourishes
